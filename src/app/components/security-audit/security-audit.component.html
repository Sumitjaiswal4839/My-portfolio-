🛡️ Threat Model & Mitigations

Threat Vector Risk Level Mitigation Implemented
Cross-Site Scripting (XSS) High Angular sanitization, SafeUrlPipe checks, and zero unsafe innerHTML/document.write usage.
Unauthorized Writes / IDOR Critical Strict Firestore & Storage Rules verifying Firebase Auth JWT tokens and admin custom claims.
Credential / State Tampering Medium Removed client-side boolean storage flags; privileges tied cryptographically to server-side auth.
Malicious File Uploads Medium Firebase Storage rules restricting uploads to PDF only (< 5MB) with strict content-type validation.
Automated Bot / Quota Abuse Low Firebase App Check (reCAPTCHA v3) integration blocking non-genuine clients.
Supply Chain Vulnerabilities Medium Automated Dependabot alerts, CodeQL SAST checks, and regular `npm audit` integration.

🎯 OWASP Top 10 Coverage & Mitigations

A01:2021 ✓ Mitigated

Broken Access Control

Enforced strict Firestore & Storage Security Rules checking server-side Firebase Auth tokens, email verification, and custom admin claims.

A02:2021 ✓ Mitigated

Cryptographic Failures

Forced HTTPS-only redirection via Netlify config along with strict HSTS headers (`max-age=31536000`) and secure Firebase Auth session tokens.

A03:2021 ✓ Mitigated

Injection (DOM XSS / Sinks)

Eliminated raw `document.write` sinks, added strict URL scheme validation (`SafeUrlPipe`), and adopted safe Angular template binding (`{{ }}`).

A05:2021 ✓ Mitigated

Security Misconfiguration

Deployed hardened Netlify security headers (CSP, X-Frame-Options, X-Content-Type-Options, Permissions-Policy) and disabled production source maps.

A06:2021 ✓ Mitigated

Vulnerable Components

Integrated automated Dependabot weekly scans, GitHub CodeQL semantic analysis, and local `npm audit` gates in GitHub Actions CI.

A07:2021 ✓ Mitigated

Authentication Failures

Removed vulnerable client-side boolean sessionStorage flags; replaced with cryptographically secure Firebase Auth and custom claims verification.
